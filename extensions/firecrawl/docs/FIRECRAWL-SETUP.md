# Firecrawl setup

Configure a compatible Firecrawl MCP server in Hermes using the provider's current documentation. The former extension installer and `~/.claude.json` example belong to the source project and do not apply to this fork. Store the API key in Hermes' secret/config mechanism and confirm that the server's tools appear in Hermes.

Firecrawl calls may consume credits and transmit the target site's URLs and content to the service. Check current pricing and limits and obtain approval for the specific crawl or scrape. Tool names and parameters depend on the provider server version; consult its current documentation rather than relying on historical examples.

No live Firecrawl service call has been verified in this fork.
